# 🟨 JavaScript — Fundamentos

Repositório didático desenvolvido para o estudo dos **fundamentos de JavaScript**, combinando explicações teóricas em Markdown com exemplos práticos executados diretamente no navegador.

A proposta é aprender os conceitos de forma **progressiva e prática**, permitindo que cada conteúdo seja estudado, testado e modificado pelo aluno.

## 📚 Conteúdo

| # | Conteúdo | Principais conceitos |
|---|---|---|
| 1️⃣ | **Variáveis e Tipos** | `let`, `const`, `string`, `number`, `boolean` |
| 2️⃣ | **Operadores** | Aritméticos, comparação, lógicos e atribuição |
| 3️⃣ | **Condicionais** | `if`, `else`, `else if`, `switch`, ternário |
| 4️⃣ | **Repetições** | `for`, `while`, `do...while`, `break`, `continue` |
| 5️⃣ | **Funções** | Parâmetros, retorno e arrow functions |
| 6️⃣ | **Arrays** | Métodos e manipulação de listas |
| 7️⃣ | **Objetos** | Propriedades, métodos e `this` |
| 8️⃣ | **DOM** | Seleção e manipulação de elementos HTML |
| 9️⃣ | **Eventos** | `click`, `input`, `change`, `submit` e outros |
| 🔟 | **Formulários** | Captura, validação e processamento de dados |
| 1️⃣1️⃣ | **LocalStorage** | Persistência de dados no navegador |
| 1️⃣2️⃣ | **Fetch e APIs** | Requisições HTTP e consumo de APIs |

## 🚀 Como utilizar

### 1. 📖 Estude o conteúdo

Comece pelo arquivo Markdown correspondente à aula.

```text
01 - Variáveis e Tipos.md
02 - Operadores.md
03 - Condicionais.md
04 - Repetições.md
05 - Funções.md
06 - Arrays.md
07 - Objetos.md
08 - DOM.md
09 - Eventos.md
10 - Formulários.md
11 - LocalStorage.md
12 - Fetch e APIs.md
```

Cada material apresenta os conceitos, exemplos de código, exercícios e desafios.

### 2. 💻 Abra os exemplos

Entre na pasta:

```text
Exemplo/
```

e abra o arquivo:

```text
index.html
```

no navegador.

### 3. 🔎 Abra o DevTools

Utilize `F12` ou `Ctrl + Shift + I`.

Depois, acesse a aba **Console** para acompanhar a execução dos exemplos JavaScript.

### 4. 🧪 Experimente

Não apenas leia o código.

**Altere os valores, execute novamente e observe o comportamento.**

Por exemplo:

```javascript
const nome = "João";
const idade = 20;

console.log(`Olá, ${nome}! Você tem ${idade} anos.`);
```

Experimente modificar os valores e observe o resultado no Console.

### 5. 📝 Resolva os exercícios

Após estudar cada conteúdo, utilize os exercícios e desafios propostos no respectivo Markdown para praticar o conceito aprendido.

### 6. 🔁 Explore e modifique

O objetivo do repositório não é apenas executar os exemplos, mas **experimentar com o código**.

> 💡 **Regra principal:** altere o código, execute novamente e tente entender por que o resultado mudou.

## 🎯 Objetivo do repositório

Ao final do percurso, o estudante deverá ter contato com os principais fundamentos necessários para começar a desenvolver aplicações utilizando JavaScript no navegador, passando da **lógica de programação** para a **manipulação de páginas web**, **interação com usuários**, **armazenamento de dados** e **consumo de APIs**.
